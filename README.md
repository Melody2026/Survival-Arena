# Neon Arena

A top-down survival game prototype built with Godot and GDScript.

## Gameplay

Survive increasingly difficult waves of enemies while aiming and shooting with the mouse.

## Features

- WASD player movement
- Mouse-based aiming
- Projectile combat
- Enemy AI
- Enemy spawning
- Wave progression
- Health and damage systems
- Invulnerability frames
- Score system
- Game-over state

## Controls

| Action | Input |
|---|---|
| Move | WASD |
| Aim | Mouse |
| Shoot | Left Click |

## Built With

- Godot
- GDScript

## What I Learned

This project was built to explore gameplay programming and game design. I iterated on enemy speed, damage, spawn rates, and player feedback through playtesting to improve the pacing and responsiveness of the game.
